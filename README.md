# مندوبك — نسخة تجهيز ما قبل الإطلاق

واجهة Web/PWA عربية RTL لمشروع مندوبك — بورسعيد. هذه النسخة تتضمن حسابات العميل والكابتن، إنشاء الطلب، قبول الطلب ذريًا، وسير حالات الكابتن الأساسي.

## 1) تثبيت قاعدة البيانات على مشروع Supabase جديد
1. افتح Supabase → SQL Editor.
2. شغّل الملف `supabase/fresh-install.sql` الموجود بجذر الحزمة **مرة واحدة على مشروع فارغ فقط**.
3. لا تشغّل `supabase/production-extension.sql` بعده؛ الملف الأخير محفوظ للتوافق مع النسخ القديمة فقط.
4. راجع Authentication → Providers وفعل Email وGoogle/Facebook حسب بيانات التطبيقات لديك.
5. في Authentication → URL Configuration اضبط Site URL على رابط الإنتاج، وأضف رابط الإنتاج نفسه إلى Redirect URLs. لا تضف localhost للإنتاج.

## 2) إعداد المفتاح
افتح `mandobk-web-foundation/config/supabase.js` واستبدل قيمة `PASTE_YOUR_SUPABASE_PUBLISHABLE_KEY_HERE` بمفتاح Publishable/anon الخاص بالمشروع. لا تضع `service_role` أو أي سر داخل ملفات المتصفح.

## 3) نشر الملفات
ارفع **محتويات** مجلد `mandobk-web-foundation` إلى جذر الاستضافة بحيث يصبح `index.html` في الجذر و`assets/` بجانبه. تأكد أن الاستضافة تدعم HTTPS وأنها تعيد `index.html` للمسارات غير الموجودة إذا أضيفت مسارات لاحقًا.

## 4) إعداد OAuth
- Google/Facebook يجب تفعيلهما في Supabase Auth Providers.
- أضف رابط الإنتاج إلى Redirect URLs في Supabase.
- Facebook Valid OAuth Redirect URI يكون رابط callback الخاص بـ Supabase، وليس رابط الموقع.
- اختبر تسجيل الدخول من الدومين النهائي، وليس من localhost.

## 5) إنشاء أول كابتن
التسجيل العام ينشئ دور `customer` دائمًا. لا يمكن للمستخدم ترقية نفسه إلى كابتن أو مدير. بعد مراجعة بيانات الكابتن، غيّر الدور وأنشئ صف `captains` من لوحة Supabase باستخدام حساب إداري موثوق، ثم اجعل `is_approved=true`. لا تفتح صلاحية تغيير الدور من المتصفح.

## الموجود حاليًا
- Email/password + Google/Facebook UI.
- ملف عميل وكابتن، واجهة عميل لإنشاء ومتابعة الطلبات.
- واجهة كابتن لتفعيل الاتصال (بعد الاعتماد)، رؤية الطلبات المتاحة، قبول الطلب ذريًا، وتحديث مراحل التوصيل المسموحة.
- إشعارات داخل الموقع، PWA، RTL ومتجاوب.
- SQL تأسيسي كامل مع RLS، سياسات محدودة، وسجلات حالة الطلب.

## حاجات لا تزال مانع إطلاق عام
هذه ليست منظومة إنتاج مكتملة بعد: لا توجد لوحة إدارة/تاجر فعلية، ولا خدمة OTP آمنة لتوليد وتسليم رمز العميل والتحقق منه، ولا توزيع تلقائي/إعادة إسناد، ولا بث موقع حي، ولا دفتر مالي تشغيلي أو اختبارات قبول شاملة. لا تعلن التشغيل التجاري قبل تنفيذها واختبارها. الدفع في هذه النسخة نقدي فقط.

## التشغيل المحلي
من داخل مجلد `mandobk-web-foundation`:
```bash
python -m http.server 5500
```
ثم افتح `http://localhost:5500`.
